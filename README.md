# 📝 PHP Survey Form
This is the PHP Survey Project - a survey form that created with HTML, CSS, and PHP.

## 💡 Purpose
This project was created for the web development level 3 course assignment.

## Installation 💻
No installation required, simply download the zip file and extract.

## 🧭 Usage
1. View the project using your preferred PHP server.
2. Fill the survey form with completing all questions.
3. Send the form to process all answers.
4. View your sended messages or validation error messages.
